The database supports various functionalities that allow you to navigate, examine, and save the data in easy and intuitive ways. Together, they help spotting linguistic patterns that only emerge when comparing and contrasting data across participants/language (varieties)/chapters/(sub)tags/constructions.

### Searching and filtering the data
You can use the search bar at the top of the questionnaire/judgments sections of the database to search through the adverbials or judgments in either corpus. By default, you will be searching through all fields, but you can also select specific fields to search through.

To search a specific field, click the dropdown menu to the left of the search bar (marked with an asterisk in the default case) and select the specific field you are interested in. For both parts of the database, these include fields for searching (sub)questions, the gloss lines, the English translation lines, language (varieties)/dialects, and participants. For the questionnaire section, these also include fields for searching all (un)attested patterns, chapters, and (sub)tags. For the grammaticality judgments section, these also include fields for searching patterns that received specific scores between 1 and 5, and specific judgments (a combination of the fill-in-the-blank sentence and the manner adverbial to be filled in participants were presented with). Some of these fields allow you to select from a dropdown list of (sometimes nested) all instances of (sub)questions/language (varieties) and dialects/participants/chapters/(sub)tags contained in the database. Other fields allow you to enter your own written search query in the search bar (see below for more information on how search queries are processed).

Searching a specific field as described above basically acts as a filter on the data presented. You can search/filter in more detail by specifying your search in multiple different fields. You can add an additional field to specify by clicking the ‘+ Add Filter’ button, at the lower left part of the search field. Multiple fields are interpreted using AND logic (meaning only data are displayed that fall into the intersection of all specified fields). You can toggle the interpretation of multiple fields to use OR logic (meaning only data are displayed that fall into the union of the data found by all specified fields) using the button on the lower right part of the search field. A single field can be deleted by clicking the trash can button next to it. All fields can be deleted by clicking the ‘x Clear Filter’ button in the lower left part of the search field.

When entering your own written search query terms in fields that allow it, you can type in multiple query terms. For example, if you type in marie schrijft, you will search for items that contain marie and/or schrijft. By default the search will combine all terms using OR. Meaning that when you type: Marie schrijft, items will be found containing Marie or schrijft.
If you want to search for fields containing both terms, search for Marie & schrijft where & is used to show that both parts should be in the field. It is also possible to search for specific phrases by surrounding them with " such as "schrijft netjes".

### Filtering made easy
In addition to using the search field to enter search queries and set up filters, you can set up some specified search fields right from the data you are looking through; some parts of the data (like language (varieties) and dialects/participants/(un)attested status/chapters/(sub)tags) are clickable buttons themselves. If you click the button itself, you add this language (variety)/participant/status/chapter/(sub)tag to your active search fields/filters. Clicking the right-most ‘x’ adds it to your active search fields/filters in order to exclude all data listed under that language (variety)/participant/status/chapter/(sub)tag.


### Downloading data
You may be interested in downloading the data you find in the database to your device to consult them again offline/more easily, or even share them. To facilitate this, there is the ‘Download’ button. Clicking this downloads all data currently displayed (taking into account your active search fields/filters) in the form of an Excel file. If you share or reproduce the data found in the database, please remember to explicitly refer to the database in the ways mentioned under ‘Citing the Database’ on the home page.
